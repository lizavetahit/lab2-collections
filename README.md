## Опис проєкту

Проєкт реалізує **частотний аналізатор тексту** — клас `ua.kpi.comsys.collections.WordCounter`:

Метод `Map<String, Integer> countWords(List<String> textLines)` Повертає відображення *слово - кількість входжень*

Метод `Set<String> getUniqueWords(List<String> textLines)` Повертає множину всіх унікальних слів


Правила обробки тексту:
- словом вважається послідовність буквено-цифрових символів латиниці (`[A-Za-z0-9]+`), усі інші символи (пробіли, пунктуація, кирилиця тощо) — роздільники;
- усі слова приводяться до нижнього регістру (`Locale.ROOT`);
- порожні слова після розбиття ігноруються;
- якщо `textLines == null`, обидва методи кидають `IllegalArgumentException("textLines cannot be null")`;
- `null`-рядки всередині списку пропускаються.

Використано лише стандартні колекції `java.util.*` (`HashMap`, `HashSet`).

## Тести

`WordCounterTest` (JUnit 5, 17 тестів) покриває:
- викидання `IllegalArgumentException` для `null` в обох методах (з перевіркою повідомлення);
- порожній список, порожні рядки та рядки лише з розділовими знаками;
- підрахунок повторень, ігнорування регістру;
- пунктуацію, табуляцію, дефіс, апостроф, підкреслення як роздільники;
- цифри як частину слова, ігнорування нелатинських символів;
- пропуск `null`-рядків усередині списку;
- незмінність вхідного списку та узгодженість `getUniqueWords` з `countWords`.
